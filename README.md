# Sales Dashboard Design

## Project Overview
This project was developed using Power BI to analyze the Sales Data 2022 dataset and create an interactive dashboard for business stakeholders.

## Tool Used
- Power BI

## Dataset
Sales Data 2022

## Dashboard Features
- KPI Cards
- Time-Series Analysis
- Product-wise Analysis
- Territory-wise Analysis
- Interactive Filters and Slicers

## KPIs
- Total Orders
- Total Quantity
- Total Customers

## Files Included
- Sales_Dashboard.pbix
- Dashboard_Summary.pptx
- Dashboard_Screenshot.png
- Sales_Data_2022.xlsx

## Outcome
Designed an interactive dashboard that helps visualize sales performance and supports business decision-making.
